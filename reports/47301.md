| | |
|---|---|

| Status | Fixed (one commit), checked on the test server by starting the event directly |
| Fix branch | [fix/47301](https://github.com/sohpea-cloub/tgstation-slop/tree/fix/47301) |
| Tested on | tgstation master `87b93338`, 2026-10-23 |

## Summary

The issue lists four possible problems with the mass mindswap wizard event (now "Change Minds!"). One was real: the event swapped minds of humans on any z-level, including miners and other people far from the station. The event's `start()` had no z-level check, and the fix adds one so only humans on a station z-level are swapped. Of the other three points, critical-condition targets were already excluded, and ejection from an open exosuit and death on ghosting follow from existing mechanics that the code shows to be deliberate. Those two were not changed.

## The bug

The reporter had not reproduced the points and asked for someone with admin tools to check them. Point by point:

1. **Critical people can be targeted.** The target filter already excludes unconscious and critical humans, so this no longer applies.
2. **People off the station z-level can be targeted.** True on master. Anyone with a mind, wherever they are (a miner, a ghost-role character, someone at CentCom), could have their mind swapped.
3. **Mindswap ejects you from an exosuit.** Real behaviour, but a consequence of a deliberate rule (below).
4. **Ghosting after a swap kills your original body.** Also a consequence of a deliberate rule (below).

## Reproduction

Only point 2 was reproduced. The event was started directly from the Lua editor rather than by waiting for the wizard event to be rolled, so the event's selection and swap code ran as in the real event, but the trigger itself was not exercised.

1. Start the round and open the Lua editor.
2. Spawn eight humans, each with a mind: four on the station z-level (z2 on the test map) and four on z1 (CentCom).
3. Run `SS13.new('/datum/round_event/wizard/shuffleminds'):start()`.
4. List each body's mind and z-level.

Result on master: minds crossed between the two z-levels. For example, a body on z1 held a mind that had started in a body on z2, and a body on z2 held a mind from z1 (minds 1-4 started on z2, minds 5-8 on z1).

## Cause

`/datum/round_event/wizard/shuffleminds/start()` (`code/modules/events/wizard/shuffle.dm:82`) builds its candidate list from `GLOB.alive_mob_list`. The loop (`shuffle.dm:85-88`) skips unconscious or critical humans, humans without a mind, wizards and `TRAIT_NO_MINDSWAP` holders, but never looks at the human's z-level. Every remaining human is shuffled into random pairs and passed to `swap_minds`.

For the other points:

- Critical targets: the same loop already has `IS_UNCONSCIOUS_OR_CRIT(alive_human)` (`shuffle.dm:86`).
- Exosuit ejection: `swap_minds` makes both parties unconscious for 40 seconds (`code/modules/spells/spell_types/pointed/mind_transfer.dm:136-137`, durations at lines 28 and 30). Open (non-enclosed) mechs eject an incapacitated occupant by design: `process_occupants` in `code/modules/vehicles/mecha/_mecha.dm:625` has `if(!(mecha_flags & IS_ENCLOSED) && occupant?.incapacitated)` followed by `mob_exit(occupant, randomstep = TRUE)`.
- Ghosting killing the body: the Ghost verb ("Relinquish your life and enter the land of the dead", `code/modules/mob/dead/observer/observer.dm:307-310`) calls `succumb()` on a living mob that is not stable. After a swap the player is in a body that is unconscious, so ghosting makes that body die. That body belongs to the other person, which explains the reporter's observation.

## Fix

One commit, **Fix issue 47301: mass mindswap (Change Minds!) only picks mobs on the station z-level**. It adds a check to the candidate loop in `start()`:

```
if(!is_station_level(alive_human.z))
	continue //only people on the station, not miners, ghost roles and so on off elsewhere
```

The check sits after the existing exclusions and before the human is added to `mobs_to_swap`. This matches what the event's description says ("everyone around the station") and what a commenter on the issue suggested. Nothing was changed for the crit, exosuit or ghosting points.

## Verification

Using the same setup as the reproduction (four minded humans on z2, four on z1, event `start()` run from Lua), after the fix:

- the four humans on z2 swapped minds among themselves (for example body 1 held mind 2, body 2 held mind 1, body 3 held mind 4, body 4 held mind 3);
- the four humans on z1 kept their own minds.

Not checked: the event firing through the normal wizard event roll or the Summon Events path; the exosuit ejection and the ghosting death were judged from the code only and not tested in game; participants on z-levels that count as station levels other than the main station (for example multi-z stations) were not tried; the unfixed "crit" case was not tested.

## Notes

- This is a design change: the event is now limited to station z-levels. Anyone on a mining base, lavaland, a space ruin or CentCom is no longer affected. That addresses the complaint in the thread about miners being swapped, but a maintainer may prefer a different scope (for example "same z-level as the wizard").
- The ghosting and exosuit behaviours could be softened separately if desired (for example by not applying the succumb on ghost to a body the player was swapped into), but that would change general ghost and mech rules, so it was not done here.
- A comment on the issue (2021) wondered whether the event had been removed; it is still present as `/datum/round_event_control/wizard/shuffleminds` (name "Change Minds!", weight 1, max 3 occurrences).
