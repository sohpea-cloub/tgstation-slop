## Summary

The 2023 report said the Supernatural phobia reacted to ghosts the victim could not see, and made them point at nothing. On current master the phobia was rewritten into a terror handler. It scans only living mobs and skips anything the owner cannot see. A ghost mob with raised invisibility did not trigger it in a test, and the pointing behaviour no longer exists.

## The bug

The report (two screenshots, which were not examined) showed a character with the Phobia of the Supernatural reacting to, and pointing at, ghosts that the character could not see.

## Reproduction

I could not reproduce it.

1. On the test server, join as an observer (a ghost with `see_invisible` 60).
2. Using the Lua editor, spawn a human ("Victim", `see_invisible` 0) with `/datum/brain_trauma/mild/phobia/supernatural`, and a `/mob/living/basic/ghost` (a type in the supernatural trigger list) with `invisibility` 60, both on the observer's tile.
3. Wait more than 20 seconds (the phobia check runs every 5 seconds). Neither the observer ghost nor the invisible ghost mob caused any reaction: the victim's `mood_events["phobia"]` and `["phobia_minor"]` stayed nil.
4. Control: set the ghost mob's `invisibility` to 0 and wait 15 seconds. The victim screamed ("AAAAH"), a startle/freak-out reaction. So the trauma and the scan work, and only visibility prevented the trigger.

This does not cover the 2023 code path itself, since that code no longer exists. A player reaction to a ghost that is visible only to some viewers was not tested.

## Cause

None on current master; the relevant code was replaced.

- The mob scan in `code/datums/components/fearful/sources/phobia.dm` iterates `for(var/mob/living/checked in view(...))` (line 57), so `/mob/dead/observer` is never examined even though it is listed under "the supernatural" in `code/_globalvars/phobias.dm:112`.
- `is_scary_mob()` (`phobia.dm:72`) returns FALSE when `checked.invisibility > owner.see_invisible || checked.alpha == 0`. The item check (`is_scary_item()`) has the same invisibility test.
- No pointing behaviour remains: a search for "point" under `code/datums/components/fearful/` found nothing. Nothing was found in `code/datums/brain_damage/phobia.dm` either.

## Fix

None.

## Verification

Only the test described above. Not checked: the old behaviour (no old build was run), invisible non-ghost supernatural mobs, and other phobias.

## Notes

- `/mob/dead/observer` in the "the supernatural" list (`phobias.dm:112`) has no effect now because the scan skips non-living mobs. It is dead weight and could be removed or left alone; it is cosmetic.
- The issue was probably fixed by the phobia rewrite into terror handlers. I did not identify which upstream PR did this.
