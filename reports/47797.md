## Summary

The 2019 issue bundles four unrelated complaints about changelings and moths. On current master all four appear to be resolved by later changes. Point 4 (a limbless moth flying slowly with its wings in zero gravity) was tested in game and did not reproduce: a moth with its arms and legs removed crossed 8 tiles in the same time as an intact moth. Points 1-3 were not run in game; the code was read and each is covered by current code (details below), so those verdicts rest on code reading alone. No fix was written.

## The bug

The issue reports four things:

1. Changeling organs can decay while the changeling is "dead" in regenerative stasis. The reporter had not tested this but reasoned that the Regenerate ability only replaces missing organs, not failed ones.
2. Middle-clicking a target to use a sting executes the sting but also swaps the active hand, which the reporter attributed to the recent hotkey changes.
3. Headless changeling moths (decapitated, e.g. by the amputation surgery) still show antennae and the frill-like markings on the back of the head.
4. Changeling moths with no limbs or head can still move with their wings in zero gravity with air (probably intended), but do so very slowly, comparable to crawling.

The reporter later commented that point 1 might not be real, since regenerative stasis probably heals all organs on revival, and that point 4 may have been fixed by a recent PR. A commenter pointed out that point 3 was dealt with by PR #53928, and asked for the issue to be split.

## Reproduction

Only point 4 was exercised in game. The test was done on the test server with the Lua editor, and the movement itself was done as a player would (walking east and west), not by calling movement procs.

1. Started the round and joined as an Assistant.
2. Using the Lua editor, turned the character into a moth (`set_species(/datum/species/moth)`).
3. Teleported the character to an open, obstacle-free stretch of Central Primary Hallway on the station z-level.
4. Removed gravity from that area by adding the `NO_GRAVITY` flag (16384) to the area's `area_flags`. Air stayed at about 101.3 kPa, `has_gravity()` returned 0 and the "Weightless" alert appeared.
5. With all limbs: recorded `world.time`, walked 8 tiles east, recorded `world.time` again.
6. Using the Lua editor, called `dismember()` on every body part except the chest and head (both arms and both legs). `usable_legs` read 0 and `usable_hands` dropped from 4 to 2. The moth's remaining hands were not removed; the character stayed standing (`body_position` 0). Teleported back to the east end of the stretch.
7. Limbless: recorded `world.time`, walked 8 tiles west, recorded `world.time` again.

Evidence:

| State | Time for 8 tiles (deciseconds) | Cached multiplicative slowdown | Movement type |
|---|---|---|---|
| All limbs | about 21.5 | 1.5 | 9 (`GROUND`\|`FLOATING`) |
| Arms and legs dismembered | about 22 | 1.5 | 9 |

The two times differ by half a decisecond, which is within the noise of the measurement (the timestamps were read through separate tool calls). There was no limbless slowdown: the slowdown value was identical in both states. The source of the 1.5 itself was not identified; it was the same with and without limbs.

Not tested: the headless case. The attempt was to make the character a changeling with the Lua editor and then dismember the head; the character died from the decapitation and the run was abandoned. That admin action also produced 19 runtimes in the runtime log (for example `Cannot read null.prefs` and `mob_login overridden`) from the dead, headless mob; they are side effects of the setup, not findings about the issue.

## Cause

Point 4 does not happen on master, and the code explains why.

- When a carbon mob gains the `FLOATING` or `FLYING` movement type, the limbless penalty is removed: `on_movement_type_flag_enabled` removes `/datum/movespeed_modifier/limbless` and the floored/immobilized traits (`code/modules/mob/living/carbon/carbon_movement.dm:47-50`). The penalty is only re-added by `on_movement_type_flag_disabled` once the mob is neither floating nor flying (`carbon_movement.dm:52-68`).
- The modifier itself is defined with `movetypes = GROUND` and `blacklisted_movetypes = FLOATING|FLYING` (`code/modules/movespeed/modifiers/mobs.dm:86-90`), so it would not apply to a floating mob anyway.
- A weightless mob in the test had movement type 9, i.e. `GROUND|FLOATING`, so the limbless slowdown was absent in both tests, matching the measurement.
- Moth wings are `WINGS_FLIGHTLESS` and drift with a small force (`MOTH_WING_FORCE`, 1 newton, `code/modules/surgery/organs/external/wings/moth_wings.dm:23`) through a jetpack component set up in `setup_jetpack()` (`code/modules/surgery/organs/external/wings/wings.dm:58-69`). It is allowed when the owner is weightless, has a client and the pressure is at least 0.85 atm (`wings.dm:170-181`). It does not depend on limbs.

The older reported slowness therefore came from an earlier movement implementation that has since been rewritten.

Points 1-3 (code reading only, not run in game):

1. Regenerate calls `carbon_user.fully_heal(HEAL_BODY)` (`code/modules/antagonists/changeling/powers/regenerate.dm:19`), and `HEAL_BODY` includes `HEAL_ORGANS` and `HEAL_REFRESH_ORGANS` (`code/__DEFINES/mobs.dm:1031`), so failed organs are repaired, not only missing ones. Reviving from regenerative stasis uses `HEAL_BODY` minus `HEAL_LIMBS` (`code/modules/antagonists/changeling/powers/fakedeath.dm:102-104`).
2. The sting click handler is registered for middle and alt click (`code/modules/antagonists/changeling/changeling.dm:143`) and returns `COMSIG_MOB_CANCEL_CLICKON` once it starts a sting (`changeling.dm:317`). `MiddleClickOn` returns before `cycle_hand(WEST, FALSE)` when that flag is set (`code/_onclick/click.dm:389-393`), so the hand is no longer swapped. The handler returns early without cancelling in some cases (no chosen sting, clicking oneself, being unconscious/in crit, a non-living target, or a target beyond `sting_range`, `changeling.dm:307-313`); in those cases the click still swaps hands, which is the normal middle-click behaviour.
3. Antennae are now a separate organ in the head (`code/modules/surgery/organs/external/_visual_organs.dm:234-240`, `zone = BODY_ZONE_HEAD`), added by PR #53928, so they leave the body with the head.

## Fix

None. No commits were made.

## Verification

Checked in game: point 4 only, as described under Reproduction, with the result that no slowdown exists.

Not checked in game: points 1, 2 and 3. In particular, no changeling was put into regenerative stasis with failed organs, no sting was fired with a middle click, and no decapitated moth was inspected for leftover antennae or head markings. Point 4 was also not checked for a headless moth, and was only measured while standing (a limbless moth lying down or crawling was not compared).

## Notes

- The issue should be split or closed; it mixes four separate topics and, going by the code, none of them appears to be open any more. The commenter already requested a split in 2020.
- For point 2, the remaining case where a middle click with a sting selected still swaps hands is any click that the handler declines (out of range, clicking oneself, unconscious, or a non-living target). If maintainers consider that a problem it would be a different report from the one filed here.
- Point 4 depends on movement type: a limbless mob on the ground in normal gravity does get the `limbless` slowdown (`carbon_movement.dm:52-68`); only floating/flying mobs are exempt.
- A zero-gravity test needs `NO_GRAVITY` on the area plus air above 0.85 atm for the moth wings to engage; both held in the test.
