# #97397: Punching mitts right click ignores pacifism (and hunter boxing can't hit basic bosses)

| | |
|---|---|
| Issues | [#97397](https://github.com/tgstation/tgstation/issues/97397): verified, fixed. [#97922](https://github.com/tgstation/tgstation/issues/97922): verified, fixed |
| Status | Both reproduced on master and fixed in two separate commits; the fixes were checked in game |
| Fix branch | [fix/97397](https://github.com/sohpea-cloub/tgstation-slop/tree/fix/97397) |
| Tested on | tgstation master `87b93338`, 2026-10-23 |

## Summary

#97397: martial arts only check for pacifism on the combat-mode (left click) path. Right click goes straight to `disarm_act()`, and the boxing styles' `disarm_act()` punches, so a pacified player with punching mitts (hunter boxing) or evil boxing could deal brute damage. Boxing's `disarm_act()` now returns `MARTIAL_ATTACK_INVALID` for pacifists when the style isn't a pacifist style, which gives the normal shove.

#97922: basic bosses (the Thing, Blood Drunk Miner) carry `TRAIT_MARTIAL_ARTS_IMMUNE`, so no martial art ever acts on them, and hunter boxing's megafauna exceptions used a type check that excludes basic bosses. Hunter boxing now opts out of the immunity and uses `ismegafauna()`, which covers bosses.

## The bug

### #97397

A player with the pacifism trait (the report used the Rod of Asclepius) who wears punching mitts and right clicks someone punches them and does damage. Left click is correctly blocked.

### #97922

With punching mitts, right click on the Thing or the Blood Drunk Miner produced a plain shove instead of a punch. Combos and blocks never triggered against them.

## Reproduction

### #97397

On the test server, using the Lua editor:

1. Spawned a human ("Atk") wearing punching mitts (`/obj/item/clothing/gloves/fingerless/punch_mitts`, hunter boxing) and given `TRAIT_PACIFISM`, and a second human ("Vic") adjacent. Took control of Atk.
2. Right clicked Vic.
3. Result on master: "You punched Vic!", and Vic had 9 brute damage.

### #97922

1. Removed pacifism from Atk. Spawned `/mob/living/basic/boss/blood_drunk_miner` and `/thing` (the Thing) next to Atk, with AI off. The Thing had to be spawned with `maploaded = FALSE` to stay where it was put.
2. Right clicked each.
3. Result on master: "You shove Miner, pushing her!" and "You shove the Thing, pushing it!". No punch.

## Cause

### #97397

`unarmed_strike()` in `code/datums/martial/_martial.dm` handles the click:

```dm
if(LAZYACCESS(modifiers, RIGHT_CLICK))
	return disarm_act(source, attack_target)

if(source.combat_mode)
	if(HAS_TRAIT(source, TRAIT_PACIFISM) && !pacifist_style)
		return NONE

	return harm_act(source, attack_target)
```

(`code/datums/martial/_martial.dm:96-103`.) The pacifism check at lines 100-101 sits only in the combat-mode branch; the right click branch returns at line 97 before it. Hunter and evil boxing set `pacifist_style = FALSE` (`code/datums/martial/boxing.dm:405` and `:431`), and `/datum/martial_art/boxing/disarm_act()` (`boxing.dm:83`) does a real punch via `tussle()`.

### #97922

Two separate things:

- `code/modules/mob/living/basic/boss/boss.dm:43` gives bosses `TRAIT_MARTIAL_ARTS_IMMUNE`, and `unarmed_strike()` returns `NONE` for such targets (`_martial.dm:90`). So no martial art does anything to them, which is why only the default punch or shove happened. Real megafauna don't have this trait.
- Hunter boxing's own megafauna exceptions (`boxing.dm:463`, `:474`, `:502`, `:508`) used `istype(..., /mob/living/simple_animal/hostile/megafauna)`, which excludes `/mob/living/basic/boss`. The Miner is `MOB_HUMANOID`, so `honor_check()` returned FALSE for it. The Thing passes the honor check through `MOB_SPECIAL`, so only the immunity trait stopped it.

## Fix

- **Fix issue 97397: punching mitts right click ignored pacifism.** Adds to `/datum/martial_art/boxing/disarm_act()`:
  `if(HAS_TRAIT(attacker, TRAIT_PACIFISM) && !pacifist_style) return MARTIAL_ATTACK_INVALID`.
  The return value makes the caller fall back to the normal shove. The fix is in boxing rather than in `unarmed_strike()`, so other martial arts' right click behaviour is unchanged.
- **Fix issue 97922: hunter boxing works on bosses.** Adds a var `ignores_martial_arts_immunity` on `/datum/martial_art` (default FALSE), checked in `unarmed_strike()` as `HAS_TRAIT(attack_target, TRAIT_MARTIAL_ARTS_IMMUNE) && !ignores_martial_arts_immunity`. Hunter boxing sets it to TRUE. The four `istype(..., megafauna)` checks became `ismegafauna()`, which also matches `/mob/living/basic/boss` (`code/__DEFINES/is_helpers.dm:228`).

Alternative considered for #97922: removing `TRAIT_MARTIAL_ARTS_IMMUNE` from bosses in `boss.dm`. That would let every martial art hit bosses, so the narrower per-style opt-in was chosen.

## Verification

On the test server after rebuilding with both fixes:

- Pacified Atk right clicked Vic: "You shove Vic!", no damage.
- Unpacified Atk right clicked the Miner: "You punched Miner!". Right clicked the Thing: "You punched the Thing!".

Not checked: blocking (throw mode) against boss attacks, and combos or crits against bosses beyond the single punch. From the code, the block path (`check_block`, `boxing.dm:329`) only needs `honor_check(attacker)` to be TRUE, which now holds for the Miner, and the attacker-side trait doesn't stop it, but this was not exercised in game. Evil boxing's pacifist behaviour was not tested directly; it shares the changed `disarm_act()`.

## Notes

- The `ignores_martial_arts_immunity` var is a design choice: only hunter boxing, which exists to fight bosses, bypasses the trait. Dropping the trait from `boss.dm` is the broader alternative.
- #97922 is filed separately upstream; the two fixes are independent commits and can be split into two PRs.
