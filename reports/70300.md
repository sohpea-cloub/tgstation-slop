# #70300: Changelings "monkified" by genetics

| Status | Not reproduced; the described behaviour no longer exists on master |

| Tested on | tgstation master `87b93338`, 2026-10-23 |

## Summary
The report described a dead changeling being monkified in the DNA machine, looking unchanged but getting "The tattered flesh doesn't fit your monkey chest!" messages, and then being knife-butchered for an easy gib. On master a dead mob cannot gain the Monkified mutation at all, a living changeling becomes an ordinary visible monkey, and the "tattered flesh" message no longer exists. Butchering living humans with a right-click is a general mechanic and not specific to this case. No fix was made.

## The bug
From the report: a changeling died, a geneticist put the body in the DNA scanner and monkified it. The changeling still looked human but received the "tattered flesh" message, and a knife then gibbed the body. The reporter believed the mob was left in a broken half-transformed state. The first commenter said the tattered-flesh text was a bug, but that monkifying people with genetics, and gibbing them that way, was not. A later commenter noted that monkeys cannot be butchered unless dead, so butchering a merely unconscious changeling would have been a bug.

## Reproduction
Not reproduced. The DNA console UI was not clicked; the console's own entry point was called instead. Using the Lua editor as an observer:

1. A human was spawned, given the changeling antagonist datum and killed (`stat` = 3).
2. `dna:add_mutation(/datum/mutation/race, "activated")` was called. This is the call the DNA console makes (`code/game/machinery/computer/dna_console.dm:773`) and that `check_block` makes (`code/datums/dna/dna.dm:520`). Result: no Monkified mutation was present, the species was still human, `stat` was still 3 and the name was unchanged. Nothing happened to the body.
3. The same changeling was revived (`revive(TRUE)`) and `add_mutation` was repeated. A "monkeyify" effect appeared and the mob ended as `/datum/species/monkey` named "monkey (NNN)": a normal, visible transformation, not left half-done.
4. A second changeling was put into fake death (`fakedeath("test")`; `stat` was 0 in this setup) and monkified. It became a monkey, was alive, and still had the changeling datum.

## Cause
There is no defect matching the report:

- `/datum/mutation/proc/on_acquiring` returns FALSE when `acquirer.stat == DEAD` (`code/datums/mutations/_mutations.dm:122`), so `/datum/mutation/race` (`code/datums/mutations/body.dm`) never calls `monkeyize()` on a corpse, and `dna.dm` removes the rejected mutation.
- A search for "monkey chest" and "tattered" found no matching message in the code (only an unrelated clothing damage prefix), and the changeling code has no monkey-specific disguise state other than the Lesser Form power.
- In `code/datums/components/butchering.dm`, automatic butchering requires `stat == DEAD` (line 61). The right-click path (around lines 71-73, `butcher_human`, with `butcher_limb` around lines 120-175) works on living humans by design, limb by limb. It is not tied to monkified changelings.

## Fix
None. No commit.
