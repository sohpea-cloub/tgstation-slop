## Summary
The issue reported that the game log for traitor progression objectives ("locate weakpoint", "hack comms console") showed contradictory states (failed, then succeeded, then missed). The progression traitor objective system that produced those log lines is no longer in master. Nothing logs traitor objective state any more, so there is nothing to reproduce or fix.

## The bug
In round 205777 the log for a "locate weakpoint" objective showed the charge detonating, then the objective "failed", then "succeeded". The log for a "hack comms console" objective showed it failed, succeeded and missed, although the hack worked and Syndicate Sleeper Agents spawned. This is as described in the issue text and screenshots; the screenshots were not available to the tester.

## Reproduction
Not attempted in game. The investigation was code-only:

1. Searched the code for `traitor_objective`, `TRAITOR_OBJECTIVE` and `OBJECTIVE_STATE_`. There is no `/datum/traitor_objective` type and no objective state defines. `code/modules/antagonists/traitor/` contains only `components/`, `contractor/`, `datum_traitor.dm` and `uplink_handler.dm`; the old objectives directory is gone.
2. Searched for the two objectives named in the issue. No such progression objectives exist.
3. Searched for callers of `log_traitor` and `LOG_CATEGORY_GAME_TRAITOR`. There are none in `code/` or `tgui/`.

## Cause
There is no remaining defect to point at. Traitors now get plain `/datum/objective` instances from `forge_traitor_objectives()` (`code/modules/antagonists/traitor/datum_traitor.dm:122`). The logging helper `log_traitor` (`code/__HELPERS/logging/antagonists.dm:2`), the category `LOG_CATEGORY_GAME_TRAITOR` (`code/__DEFINES/logging.dm:154`), its category datum (`code/modules/logging/categories/log_category_game.dm:31`) and the config flag `log_traitor` (`code/controllers/configuration/entries/general.dm:139`) are still defined, but nothing calls the helper. The removal of the progression objective system appears to have landed before the most recent changelog; `git log -S traitor_objective` pointed at a commit whose changelog is for PR 98187 (found by search, not examined further).

## Fix
None. No commit was made.
