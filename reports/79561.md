# #79561: Invincibility wizard event cures things it should not (monkey humanization, Curse of Madness)

| | |

## Summary

The wizard "Invincibility" event gives every living human 40 units of adminordrazine, a debugging chemical whose full heal also cures brain traumas, negative mutations, diseases and more. That is why it removes Curse of Madness traumas (#76450). The fix gives the event its own reagent that heals only what keeps people alive, and leaves everything else alone. The other report, #79561 (monkeys turning human), could not be reproduced on current master: the Monkified mutation is already excluded from this kind of healing, and monkeys stayed monkeys.

## The bug

Both reports describe the Invincibility event, which a Grand Ritual can trigger as its random event (`summon_round_event()` in `code/modules/antagonists/wizard/grand_ritual/grand_rune.dm:200` picks any eligible round event, and the event has a wizard trigger potency range of 0 to 7). In #76450 a wizard cast Curse of Madness, then the event ran, and the curse's brain traumas were gone. In #79561 a monkey wizard with many summoned monkeys saw all of them humanize after a ritual with this outcome, and the monkeys then killed the wizard.

## Reproduction

All on the test server with the Lua editor and a ghost observer. The event's `start()` proc was called directly, not through an actual Grand Ritual, and no wizard was involved.

### #76450 (reproduced on master)

1. Spawn a human. Give it a brain trauma with lobotomy-level resilience (`gain_trauma_type` with `/datum/brain_trauma/mild` and resilience 3). Curse of Madness gives its traumas with that same resilience (`code/modules/spells/spell_types/madness_curse.dm`, `give_madness()`), so this stands in for the curse.
2. Add 40 units of `/datum/reagent/medicine/adminordrazine` to that human, which is what `code/modules/events/wizard/invincible.dm:14` does.
3. Wait about 10 seconds and count the human's traumas.

Observed: the human had 1 trauma before and 0 after.

### #79561 (not reproduced)

1. Spawn a monkey with `/mob/living/carbon/human/species/monkey` (the type the Summon Simians spell creates is the `/angry` subtype) and a second human turned into a monkey with `monkeyize()`.
2. Add 40 units of adminordrazine to both and wait about 10 seconds.

Observed: both stayed on the monkey species (`/datum/species/monkey`, id `monkey`) and were still monkeys when checked at the end. Nothing humanized them.

Limit of this test: `monkeyize()` sets the species directly (`code/modules/mob/transform_procs.dm:30-35`) and does not give the human the Monkified DNA mutation, so the second monkey did not carry that mutation. The run did not check whether the mutation was present. The code analysis below covers the mutation path.

## Cause

Adminordrazine heals on every metabolism tick through `fully_heal(full_heal_flags & ~HEAL_ALL_REAGENTS)` (`code/modules/reagents/chemistry/reagents/medicine_reagents.dm:70-75`). Its default flags are:

```dm
var/full_heal_flags = ~(HEAL_BRUTE|HEAL_BURN|HEAL_TOX|HEAL_RESTRAINTS|HEAL_ORGANS)
```

That is nearly every flag, including `HEAL_TRAUMAS`, `HEAL_NEGATIVE_MUTATIONS`, `HEAL_NEGATIVE_DISEASES` and `HEAL_ADMIN`.

- `HEAL_TRAUMAS` makes `fully_heal()` call `cure_all_traumas(TRAUMA_RESILIENCE_MAGIC)` (`code/modules/mob/living/carbon/carbon.dm:696-697`). That strips every trauma up to and including magic resilience, which covers Curse of Madness (lobotomy resilience, 3). This is #76450.
- `HEAL_NEGATIVE_MUTATIONS` removes every non-positive mutation that has `remove_on_aheal` set (`code/modules/mob/living/carbon/human/human.dm:688-692`). Removing the Monkified mutation (`/datum/mutation/race`) runs its `on_losing()`, which calls `humanize()` (`code/datums/mutations/body.dm:263-274`). That is the mechanism behind #79561, as suggested in the issue comments.

On current master the Monkified mutation sets `remove_on_aheal = FALSE` (`code/datums/mutations/body.dm:247`), so the full heal skips it and #79561 no longer happens through this path. When that line was added was not established. Summoned monkeys are species monkeys without the mutation and were not affected in the test either.

## Fix

Commit "Fix issue 76450: Invincibility wizard event no longer cures brain traumas and mutations" does two things:

- adds `/datum/reagent/medicine/adminordrazine/invincibility` ("Invincibility Draught") in `medicine_reagents.dm`, a subtype of adminordrazine with `full_heal_flags = HEAL_DAMAGE|HEAL_LIMBS|HEAL_WOUNDS|HEAL_BLOOD|HEAL_TEMP|HEAL_STATUS|HEAL_CC_STATUS`;
- changes the event to add this reagent instead of plain adminordrazine.

The subtype keeps adminordrazine's per-tick brute, burn and toxin healing and its analgesia trait, which it inherits. Plain adminordrazine, the admin chemical, is unchanged and still cures traumas, as the issue discussion suggests it should. A bespoke reagent was used rather than changing the plain chemical, following the comments on #76450 ("Might need a bespoke chem that keeps you alive without healing everything"). Rewriting the event so that it does not use a reagent at all was not attempted.

Compared with the default flags, the new reagent no longer sets `HEAL_ADMIN`, `HEAL_REFRESH_ORGANS`, `HEAL_TRAUMAS`, `HEAL_NEGATIVE_DISEASES` or `HEAL_NEGATIVE_MUTATIONS`.

## Verification

After rebuilding, a human with 2 brain traumas (mild and severe, resilience 3), 60 brute damage and 25 oxygen damage, plus a species monkey and a `monkeyize()` human, were present while the event's `start()` was run. About 10 seconds later: both monkeys were still on the monkey species, the human still had 2 traumas, brute and oxygen damage were 0, and the reagent present was "Invincibility Draught". The runtime log of that round showed no runtime errors.

Not checked:

- a real Grand Ritual or a real Invincibility event roll (only `start()` was called);
- a real Curse of Madness cast (a stand-in trauma was used);
- a human who is a monkey through the Monkified mutation, before or after the fix;
- the effect of dropping `HEAL_ADMIN`, for example on the cursed status effect or changeling and heretic debuffs that key on that flag (`code/datums/status_effects/debuffs/cursed.dm`);
- that the 40 units still last the intended "100 ticks" of protection, and that a gibbing or dying player is handled the same as before.

## Notes

- #79561 is closed as already fixed on master only for the species-monkey case and by code reading for the mutation case (see the limit above). Anyone wanting to confirm it fully should test a human given `/datum/mutation/race` through a DNA injector, then give them 40 units of plain adminordrazine.
- The new reagent also means the event no longer cures diseases or negative mutations of every player. If the event was meant to remove, say, a disease, that is now lost. The issue comments argue that this is not what the event should do.
- Other users of plain adminordrazine elsewhere in the code (for example a status effect that injects it at `code/datums/status_effects/buffs.dm:451`, and disease cure lists) were not changed or tested.
