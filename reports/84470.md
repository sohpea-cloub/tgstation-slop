## Summary

The issue consists of one screenshot and the repro line "tile spray a smooth tile", with no text saying what is wrong. The tile sprayer no longer exists on master: it was merged into the decal painter by the "Decal Painter refactor + merge with tile sprayer" change (PR #91915). On the test server, tile decals painted onto smooth floor tiles rendered the same as mapped decals, so nothing was reproduced and no fix was written.

## The bug

The report was filed on 2024-06-29 (client 515.1639). Its body is an image of a chapel-like area with a red-tinted, gridded floor. No text describes the expected or actual behaviour, so the symptom is unknown. The triage guess was that the sprayer recolours special tile types, such as smooth tiles, wrongly.

## Reproduction

Not reproduced. What was tried on master, with admin tools:

1. Using the Lua editor, spawn an `/obj/item/airlock_painter/decal` (the current tile painter).
2. `ChangeTurf` a 4x4 patch to `/turf/open/floor/iron/dark/smooth_large` (also tried `smooth_edge` and plain `iron`).
3. Set the painter's `selected_decal_icon_state` to `tile_full` and `selected_color` to `#FF0000`, and call `paint_floor` on two of the tiles.
4. On two other tiles, place a mapped `/obj/effect/turf_decal/tile/red/full`.
5. Render the area.

Result: painted and mapped tiles looked the same (red with a faint grid). No runtimes. A later render lost icons from the client's cache, so further comparisons could not be made.

## Cause

None found. For reference, in current code `paint_floor` (`code/game/objects/items/tools/engineering/painter/decal_painter.dm:40`) adds a `/datum/element/decal` using `icons/turf/decals.dmi` with the chosen state, dir, alpha and colour, and no explicit layer or plane (`:46-54`), so the decal uses the default `FLOAT_LAYER`. This is the same as the old sprayer did when the issue was filed (checked in the code at tgstation commit `ddffce34`, 2024-06-29, `/obj/item/airlock_painter/decal/tile`). Mapped `/obj/effect/turf_decal` objects use `TURF_DECAL_LAYER` (`code/game/objects/effects/decals/decal.dm:54`). That layer difference is the only difference found between painted and mapped decals. No tile type was found where it is visible, so this is an unverified guess, not a finding.

## Fix

None.

## Verification

Not applicable. What was not checked: any other tile types, floor overlays beyond the smooth iron variants listed above, and whether the layer difference ever shows with other overlays on a tile.
