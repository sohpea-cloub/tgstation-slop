# #94561: Circuit boards are treated as proper nouns

| | |
|---|---|
| Issues | [#94561](https://github.com/tgstation/tgstation/issues/94561): verified |
| Status | Fixed and checked on the test server |
| Fix branch | [fix/94561](https://github.com/sohpea-cloub/tgstation-slop/tree/fix/94561) |
| Tested on | tgstation master `87b93338`, 2026-10-23 |

## Summary

Most circuit boards have capitalized names such as "Autolathe (Machine Board)". The name is rebuilt in `/obj/item/circuitboard/Initialize()` without `\improper`, so BYOND treats it as a proper noun and examine text gets no article. The fix adds `\improper` to the three places where a board's name is built from its initial name and `name_extension`. Examining a board now reads "an Autolathe (Machine Board)".

## The bug

Examining a board such as the autolathe board gives text without an article, as if "Autolathe (Machine Board)" were a person's name. A capitalized name that does not start with `\improper` counts as a proper noun, so `\a` and `\the` add no article. The issue comments say a few boards do carry `\improper`, but most do not.

## Reproduction

1. On the test server, open the Lua editor as an admin and create a state.
2. Spawn boards at your turf and call `get_examine_name` on each, printing it next to `name`. The types were `/obj/item/circuitboard/machine/autolathe`, `/obj/item/circuitboard/computer/powermonitor`, `/obj/item/circuitboard/computer/cargo` and `/obj/item/circuitboard/machine/hydroponics`.
3. Read the return values from the Lua state log.

Observed on master:

- `Autolathe (Machine Board)`
- `Power Monitor (Computer Board)`
- `Supply Console (Computer Board)`
- `Hydroponics Tray (Machine Board)`

None has an article. `name` and the examine name are identical. This reproduced the naming through `get_examine_name`, not a player examining the board in the game window.

## Cause

`code/game/objects/items/circuitboards/circuitboard.dm:26-27`:

```dm
if(name_extension)
	name = "[initial(name)] [name_extension]"
```

Every board that sets `name_extension` (the "(Machine Board)" and "(Computer Board)" suffixes) has its name rebuilt here. The names are written as capitalized text, and only a few carry `\improper`. The macro in the base name is lost anyway, because the rebuild uses `initial(name)` and is not itself marked. The result is a capitalized name with no `\improper`, which BYOND treats as a proper noun.

`code/game/objects/items/circuitboards/machines/machine_circuitboards.dm:1332` and `:1336`, in `hydroponics/proc/changeindicators()`, do the same when the indicator location is toggled: `"Hydroponics Tray [name_extension]"` and `"Hydroponics Tray (Alt) [name_extension]"`.

## Fix

One commit, "Fix issue 94561: circuit boards are no longer treated as proper nouns". It prefixes `\improper ` to the three name assignments above, and adds a comment in `circuitboard.dm` explaining that board names are capitalized but are not proper nouns.

The alternative was adding `\improper` to each of the roughly 300 board names. Fixing the rebuilt name centrally covers all of them, including future boards, with a three-line change. The visible name is unchanged.

## Verification

After rebuilding, the same Lua calls on the test server returned:

- `an Autolathe (Machine Board)`
- `a Power Monitor (Computer Board)`
- `a Power Flow Control Console (Computer Board)` (this board's name already had `\improper`; no doubled-macro problem showed)
- `a Hydroponics Tray (Machine Board)`
- `a Hydroponics Tray (Alt) (Machine Board)`, after calling `changeindicators()` on the hydroponics board

`name` still displayed the same text as before.

Not checked: examining a board as a player in the game window, other board types beyond those listed, and boards created through other paths such as machine deconstruction.

## Notes

- The check used `get_examine_name`, not the examine verb output.
- Boards whose names already included `\improper` were not affected by the change.
