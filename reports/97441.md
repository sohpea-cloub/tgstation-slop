## Summary

The server side of the Spawn verb works fine with no arguments. The problem is in the tgui panel's command bar: on Enter it only autocompleted a verb that takes arguments (turning `spawn` into `spawn `) and did not run it. The fix runs the verb immediately when the typed text exactly matches the suggested verb's name.

## The bug

As an admin, typing `spawn` in the command bar and pressing Enter appeared to do nothing, so some argument had to be typed just to open the spawn panel. The reporter thought this was a regression.

## Reproduction

The client-side behaviour could not be reproduced end to end, because the test setup does not run the panel's JavaScript. What was checked:

1. Ran the Spawn verb through the server's verb path (the `verbs/invoke` message with empty args, and the command directly). Both opened the spawn search window with no runtimes, so the DM side handles no arguments correctly.
2. Read the command bar code to find why Enter did nothing (see Cause).

## Cause

In `tgui/packages/tgui-panel/verbs/CommandBar.tsx`, the Enter handler (`:587`) with a suggestion but no selected verb does:

```tsx
const verb = verbSuggestions[selectedIndex];
if (verb.args.length === 0) {
	// invoke
} else {
	selectVerb(verb);   // :599
}
```

(`:591`.) The Spawn verb declares an argument (`VERB_ARG(object, ...)` in `code/modules/admin/admin.dm:38`), so Enter only called `selectVerb()`, which changed the input to `spawn ` and invoked nothing. A second Enter was needed. Verbs with no arguments run at once, hence the inconsistency.

## Fix

**Fix issue 97441: command bar runs a fully typed verb name on Enter.** The condition became `verb.args.length === 0 || exactMatch`, where `exactMatch` is true when the kebab-cased verb name equals the input, case-insensitively. Partial input still autocompletes into the verb with its argument placeholder. For an exact match the server prompts for any missing argument, or opens its own UI as Spawn does.

## Verification

The tgui build compiled successfully. The change was not exercised in a real client or visually.

## Notes

- Side effect: typing a full name such as `jump-to-area` and pressing Enter now invokes the verb and prompts for the argument, instead of switching to the argument suggestions. Pressing space still selects the verb for argument entry.
