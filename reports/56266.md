## Summary

These three plasmaman issues were looked at together. #56266 (a spaceproofed armor vest stopping plasmaman self-ignition) no longer applies: ignition now goes through `is_atmos_sealed()`, which needs a covered chest, a covered head and covered hands, and a proofed vest alone burns. #56352 is real: `is_atmos_sealed()` only counted gloves when the plasmaman had all their hands, so a one-armed plasmaman could never be sealed. It now counts gloves on the hands that remain. #95178 is real: the plasmaman tongue overrides only the scream, so gasps used the male or female human sounds depending on body type. The tongue now also overrides `gasp` and `gaspshock` with a mixed pool.

## The bug

- **#56266.** In 2021 a plasmaman who wore a spaceproofed item in the exosuit slot (an armor vest edited to be spaceproof) without their envirosuit could live without burning. A comment in 2024 narrowed it: proofing a jumpsuit already worked, but proofing an exosuit-slot item did not make a plasmaman burn.
- **#56352.** A plasmaman who loses an arm cannot be sealed in their envirosuit any more. Screenshots in the issue show the burning. Commenters called it an oversight and also emergent gameplay, and one asked for it to be accounted for.
- **#95178.** Plasmamen have a custom scream, but other vocal emotes fall back to human sounds. Gasping played a female-sounding gasp. The issue says plasmamen have no sexes and that the female sound is the wrong thing to fall back to.

## Reproduction

All three were checked with the Lua editor on the test server, as an observer in a fresh round on station air. Humans were spawned, turned into plasmamen with `set_species`, and dressed with `equip_to_appropriate_slot`. "Sealed" below is the return value of `is_atmos_sealed(PLASMAMAN_PREVENT_IGNITION, TRUE)`, which is what the ignition effect uses.

### #56266 (not reproduced)

1. Spawn a plasmaman and give it only an armor vest with `STOPSPRESSUREDAMAGE` added to its `clothing_flags`.
2. Check sealed, and watch whether it ignites.

Observed: sealed was `0` and the plasmaman caught fire. When the same vest was combined with a plasmaman helmet and black gloves, sealed was `1` and no fire started. So a proofed vest alone no longer protects.

### #56352 (reproduced)

1. Spawn a plasmaman wearing the envirosuit-equivalent items (plasmaman jumpsuit and helmet) and black gloves.
2. Check sealed, then dismember the left arm (`num_hands` becomes 1) and check again.

Observed before the fix: sealed was `1` with both arms and `0` after the arm was lost, and the one-armed plasmaman caught fire.

### #95178 (checked by sound pool)

The sound was not heard in a client. Instead, the sound the gasp emote would choose was drawn 40 times for each test mob using the emote's `get_sound`.

1. Spawn a human with female physique, a male plasmaman and a female plasmaman.
2. Draw gasp sounds for each.

Observed after the fix (the unfixed pool for plasmamen was not drawn; see Cause for how it is chosen):

- Female-physique human, as a control: only female gasp sounds (3 distinct).
- Male and female plasmamen: all 5 gasp sounds (2 male and 3 female distinct).

## Cause

### #56266

The old suit-slot logic described in the issue is gone. Self-ignition is the `plasma_based` bodypart effect (`code/modules/surgery/bodyparts/bodypart_effects/plasma_based.dm:17`), which skips ignition only when `is_atmos_sealed(additional_flags = PLASMAMAN_PREVENT_IGNITION, check_hands = TRUE)` returns true. That proc is at `code/modules/mob/living/carbon/human/human.dm:1051`. It requires an equipped clothing item that covers the chest and has `STOPSPRESSUREDAMAGE` or the extra flag, a head that is covered the same way (or `TRAIT_HEAD_ATMOS_SEALED`), and, with `check_hands`, an item covering the hands. A vest does not cover the head or hands, so it is not enough.

### #56352

The same proc, `code/modules/mob/living/carbon/human/human.dm:1057`:

```dm
if ((equipped.body_parts_covered & HANDS) && num_hands >= default_num_hands)
	hands_covered = TRUE
```

Gloves only counted when the mob had at least the default number of hands. After losing an arm, `num_hands` is below the default, so `hands_covered` stayed `FALSE` and `is_atmos_sealed(check_hands = TRUE)` was always false. The envirosuit's extinguishing logic (`code/modules/clothing/spacesuits/plasmamen.dm:45`, `code/modules/clothing/under/jobs/Plasmaman/civilian_service.dm:47`) and the ignition effect both call it with `check_hands = TRUE`.

### #95178

`/datum/emote/living/gasp` (`code/modules/mob/living/emote.dm:206`) has default sounds keyed by `MALE` and `FEMALE` for humans. `get_emote_sound_from_list()` (`code/__HELPERS/mobs.dm:735`) picks the list for `physique`, so the sound follows body type. A tongue can override emote sounds through `emote_sounds` (read at `code/modules/surgery/organs/internal/tongue/_tongue.dm:186`). The plasmaman tongue (`_tongue.dm:585-600`) only defined the scream, so gasps fell through to the physique-based human sounds.

## Fix

Two commits on the branch; nothing for #56266.

- **"Fix issue 56352: plasmamen who lost an arm can no longer be sealed in an envirosuit".** In `is_atmos_sealed()`, `hands_covered` now starts as `!num_hands` (a mob with no hands has nothing to cover), and any clothing that covers `HANDS` sets it, with the `num_hands >= default_num_hands` condition removed. A one-armed plasmaman with gloves counts as covered, an armless one counts as covered, and a one-armed plasmaman without gloves does not.
- **"Fix issue 95178: plasmamen gasp no longer depends on body type".** The plasmaman tongue's `emote_sounds` now also has entries for `gasp` and `gaspshock`, each holding all five existing human gasp sounds with no `MALE`/`FEMALE` key, so one is picked at random regardless of physique. No plasmaman-specific gasp sound exists in the tree, so this reuses the existing ones.

## Verification

#56352, on the test server after rebuilding:

| Case | Sealed | Result |
|---|---|---|
| one arm, gloves (plus envirosuit items) | 1 | |
| no arms | 1 | |
| one arm, no gloves | 0 | |
| two arms, no gloves | 0 | |

The sealed one-armed and armless plasmamen did not ignite over about 15 seconds. The unsealed ones burned (two arms, no gloves is logged as catching fire). No runtime errors were logged.

#95178: the draws listed above, and the build compiled without errors.

Not checked: the gasp sounds in a real client, other emotes, other species, and the gaspshock pool by draw (it uses the same pool as gasp and was only checked by reading the code).

## Notes

- **#56266:** the vest case now behaves as the maintainers describe for chest-only protection. A plasmaman with a proofed vest, helmet and gloves is sealed. Whether a proofed chest item alone should protect was not changed.
- **#56352 design:** the reporter thought this was "emergent gameplay". An alternative would be a different rule for amputees, such as requiring a prosthetic. The fix takes the simple reading: cover the hands you have. A plasmaman who loses both arms is treated as sealed on the hands side, which may be debatable.
- **#95178 design:** the issue text can also be read as wanting plasmamen silent, or wanting a unique plasmaman gasp. There is no plasmaman gasp asset, so the fix used the mixed pool of the existing sounds. A maintainer may prefer silence or a new sound.
