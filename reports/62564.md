## Summary

The report says prison jumpsuits made by washing a jumpsuit with handcuffs do not count for the prison jumpsuit cargo bounty. The washer does only change appearance, so a type-based bounty could never match such a suit. However, no prison jumpsuit bounty exists in the current tree, so the symptom cannot occur. This was established by reading the code only; nothing was run in game.

## The bug

A player washed a jumpsuit with handcuffs, got something that looks like a prisoner jumpsuit, and could not use it for the prison uniform bounty. Commenters pointed out that the washer's result is cosmetic and that real prison uniforms come from the crafting menu.

## Reproduction

Not reproduced. The intended steps (wash a jumpsuit with handcuffs, then try to fulfil the prison uniform bounty) cannot be completed because there is no such bounty to fulfil. The code was searched for one:

- `prison`, `prisoner`, `jumpsuit`, `uniform` and `clothing/under` in `code/modules/cargo/bounties/` and `code/game/machinery/civilian_bounty/` turned up only unrelated entries: a patrol-area list (`bounties/security.dm:51`), the IED bounty description (`bounties/assistant.dm:176`) and the nitrium bounty description (`bounties/atmos.dm:32`).
- No `datum/bounty/item/security` exists, and the spy bounties (`code/modules/antagonists/spy/spy_bounty.dm`) have no clothing entry.
- Nothing does `istype` or `typesof` on `/obj/item/clothing/under/rank/prisoner`. It is only used by the crafting recipe (`code/datums/components/crafting/tailoring.dm:253-262`), wardrobes and lockers, the gulag teleporter and fugitive outfits.

No in-game check of the bounty list was run.

## Cause

The original cause matches the comments. The washer maps `DYE_PRISONER` to `/obj/item/clothing/under/rank/prisoner` and its skirt (`code/game/machinery/washing_machine.dm:25` and `:49`), but `dye_item()` (`:249`) only copies the target's appearance (name, icon, greyscale) onto the existing item. The item keeps its original type (for example a colour jumpsuit), so a bounty matching the prisoner jumpsuit type would not accept it. The bounty that triggered the report appears to have been removed in a later bounty rework; the shallow history available did not show which commit.

## Fix

None.

## Verification

None beyond the static code search described above.

## Notes

- Upstream PRs #63722 and #63603 mention this issue but are closed, not merged.
- The same design question remains for any future type-based check on clothing: a washer-dyed item looks like the target but is not its type. The issue comments discuss making dyed items distinguishable or synonymous; nothing was decided or tested here.
- Suggested resolution: close as obsolete, unless a maintainer knows of a bounty that still checks this type.
