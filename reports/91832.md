## Summary

Both issues are about the Vend-a-tray, the card-reader-locked display case that sold items. Upstream PR #98063, "Remove holopay stand and vend-a-tray, add tip jars", is already in master `87b93338`, so neither bug can occur. This was established by reading the code; no in-game reproduction was attempted, and the server was only started to confirm that it boots. The only leftover is two stale hint strings on the display case chassis.

## #91832: Vend-a-tray can be used by everyone

### The bug

The report said that once a Vend-a-tray was registered to a character's ID and closed with a priced item inside, any other character could open it by using their own ID on it, without paying.

### Reproduction

Not attempted in game. On master there is no `/obj/structure/displaycase/forsale` type and no sale price or payment code in the tree, so the described steps cannot be performed. Searching `code/` for "vend-a-tray" finds only the two lines below.

### Cause

Not applicable at master. The removal is in upstream commit "Remove holopay stand and vend-a-tray, add tip jars (#98063)", dated 2026-10-16 in the history available here, which is included in the tested commit. An older path-update script for the earlier board removal exists in `tools/UpdatePaths/Scripts/93517_VendATray_BoardRemove.txt`.

## #70134: Cargo budget card can be drained through a private purchase

### The bug

The 2022 report described an exploit: register a Vend-a-tray to a personal ID, then pay for an item with the Cargo Budget card (1000 credits each time), put the item back, close the tray and repeat, moving the whole cargo budget into the personal account. Comments disagree on whether this was a bug or intended: one maintainer called it working as designed, another said the budget card is meant to be deposit-only, one commenter could not reproduce it, and a later one posted a screenshot that it worked.

### Reproduction

Not attempted in game, for the same reason as above: the private-purchase path no longer exists on master.

### Cause

Not applicable at master. The same removal deleted the display case's payment code.

## Fix

None was made, and no branch contains changes for this unit.

## Verification

Code only: no `forsale` display case type, no `sale_price` or payment handling, and no holopay code in the tree. The test server was started once to confirm that the build boots and was then stopped.

## Notes

- Leftover from the removal: `/obj/structure/displaycase_chassis` still mentions the Vend-a-tray in two places in `code/game/objects/structures/displaycase.dm`: the screentip "Construct Vend-A-Tray" (line 276) and the examine hint "...or turned into a Vend-A-Tray using a card reader" (line 287). The chassis `item_interaction` (lines 302-327) only handles airlock electronics and glass, so using a card reader does nothing. These strings could be removed in a cleanup; that was not done here.
- Both issues can be closed as obsolete, pointing at #98063.
