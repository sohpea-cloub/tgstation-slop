# #89879: Feral Instincts (monkey AI) screeches almost continuously

## Summary

A mob driven by the monkey AI, including a human with the Feral Instincts (primal instincts) trauma, re-rolled its battle screech every second with a cooldown of 0.5 seconds instead of the intended 5. The behavior tree conversion wrote the cooldown as a bare `5`, which the cooldown decorator reads as deciseconds. The fix writes `"5 SECONDS"` and regenerates the compiled tree.

## The bug

The issue says there never seems to be a cooldown on screeching, so a Feral Instincts character runs around screaming instead of fighting. On master the mob screeched roughly every 5 seconds while in combat.

## Reproduction

1. On the test server, start the round and observe. In the Lua editor, spawn two humans, A and B.
2. Give A the primal instincts trauma with `gain_trauma`, clear its forced-off state, and set the monkey-aggressive blackboard value so that A attacks B.
3. Count A's emotes by hooking the `mob_emote` signal from Lua, and read the chat.
4. Observed over about 105 seconds: about 19 screech/roar emotes (8 screeches and 11 roars by the chat summary), roughly one every 5 seconds, with no effective cooldown.

## Cause

In `code/datums/ai/monkey/monkey_combat.bt.json:219`, the battle screech node is wrapped in a cooldown decorator with `"cooldown_duration": 5`. The decorator (`code/datums/ai/generic_decorators/check_cooldown.dm`) takes deciseconds, so that is 0.5 seconds. The intended value is 5 seconds, per `code/datums/ai/monkey/monkey_bt_nodes.dm:2`. The subplan loops every second (`loop_delay` 10) and rolls `random_chance` 0.25, so the effective rate was about one screech every 4 seconds.

## Fix

One commit, "Fix issue 89879: monkey AI battle screech cooldown was 0.5s instead of 5s":

- `cooldown_duration` in `monkey_combat.bt.json` changed from `5` to `"5 SECONDS"`.
- The checked-in compiled tree (`build/behavior_trees/code/datums/ai/monkey/monkey_combat.bt.compiled.json`) was regenerated; its value changed from 5 to 50.

## Verification

After rebuilding and restarting, the same setup produced 7 screech emotes in about 100 seconds (counted from the `mob_emote` signal). The blackboard value "Battle Screech Cooldown" read 1293.5 against a world time of 1656, consistent with the key being set to the current time plus 50 deciseconds after a screech about 41 seconds earlier.

Not checked: whether the tuned rate feels right to players, and other monkey AI users beyond the trauma case (the shared tree is the same).

## Notes

- The recruit cooldown in the same file (line 196, `"cooldown_duration": 10`) is also in deciseconds. It is harmless because the subplan's `loop_delay` is 5 seconds, but it has the same form of mistake.
- The agents reported no overlap with another branch touching the monkey AI (different files).
