## Summary

The report said that an active watcher hatchling disappears from above the player's head and stops firing at enemies once it is put in a bag, so it only works while held. On master the hatchling kept orbiting its owner and kept shooting after being put into a worn backpack, into a box inside the backpack, and into a box held in hand. The code checks the whole container chain, so bags should not matter. The report dates from June 2024; the change that fixed it, if there was one, could not be found because the available history is shallow.

## The bug

As reported, after using the hatchling (activating it) and putting it in a bag, the small watcher above the owner's head vanished and no longer fired at enemies. The reporter noted that the hatchling used to keep working in a bag and knew of no PR that changed this.

## Reproduction

Not reproduced. Steps taken on master with admin tools:

1. Start the round on the test server and become an observer, then wait for initialization to finish.
2. In the Lua editor, spawn a human, put a backpack on its back, and put a `watcher_hatchling` in its hand. Call `attack_self` on the hatchling, which creates the orbiter.
3. Insert the hatchling into the worn backpack: once through the Lua editor (`atom_storage` insert), and once as a player-controlled mob by activating the hatchling and clicking the backpack in the HUD. The game replied "You put the watcher hatchling into the backpack."
4. Variants through the Lua editor: the hatchling in a box nested inside the worn backpack, and in a box held in hand.

Observed after every insert:

- The hatchling's `orbiter` was still set, at alpha 255, on the owner's turf.
- It followed the owner when the owner walked (the orbiter moved from 107,144 to 108,144).
- With the hatchling in the backpack, a goliath spawned nearby was hit 14 times with "The goliath is hit by a hatchling beam!".
- The orbiter still reacted to the owner dying (it "emits a piteous keening") and to the owner being revived.
- No related runtimes appeared.

## Cause

None found at master. The hatchling's `Moved()` (`code/modules/mapfluff/ruins/lavalandruin_code/watcher_grave.dm:115`) only recalls the orbiter when the mob holding it differs from the owner:

```dm
/obj/item/watcher_hatchling/Moved(atom/old_loc, movement_dir, forced, list/old_locs, momentum_change)
	. = ..()
	if (isnull(orbiter))
		return
	var/mob/holder = recursive_loc_check(src, /mob)
	if (holder != owner)
		watcher_return()
```

`recursive_loc_check` (`code/__HELPERS/game.dm:214`) walks the full `loc` chain up to the first mob, so a bag, or a bag inside a bag, still resolves to the owner and nothing is recalled.

## Fix

None. No commit was made.

## Verification

Only the checks listed under Reproduction. Not tried: MOD suit storage, bluespace or other special bags, and putting the hatchling in a bag worn or carried by a different mob (which the code does recall). The code path for these is the same loc-chain walk, but they were not run.
