# #95894: Plasma Fixation heals from plasma internals for hosts with TRAIT_NOBREATH

| | |
|---|---|
| Issues | [#95894](https://github.com/tgstation/tgstation/issues/95894): fixed |
| Status | Fixed; verified by calling the symptom's `CanHeal()` directly, not through a full virus cycle |
| Fix branch | [fix/95894](https://github.com/sohpea-cloub/tgstation-slop/tree/fix/95894) |
| Tested on | tgstation master `87b93338`, 2026-10-23 |

## Summary

The Plasma Fixation symptom counts "breathing" plasma from an internals tank as a healing source, but it never checks whether the host breathes. A host with `TRAIT_NOBREATH` (for example from the Self-Respiration symptom) never draws gas from the tank, so it heals for as long as it likes without the tank draining. The fix adds `!HAS_TRAIT(carbon_host, TRAIT_NOBREATH)` to the internals condition, so such hosts get no healing from the tank.

## The bug

Plasma Fixation heals from three sources: plasma in the air, plasma in the bloodstream (which has to be actually metabolizing), and plasma breathed through internals, scaled by the tank's distribution pressure. A non-breathing host does not take gas from its internals tank, so the tank never empties. A virus with both Self-Respiration and Plasma Fixation lets a player set a plasma tank as internals and heal indefinitely. The issue notes the inconsistency with the bloodstream check, which requires the plasma to be metabolized.

## Reproduction

The full virus lifecycle (infection, waiting for stage 4+) was not run. The symptom's healing calculation was called directly.

1. On the test server, as an observer, use the Lua editor to spawn a human, add `no_breath` to it, and put a breath mask on it.
2. Spawn a plasma internals tank, put it in the human's hands, and call `open_internals()` with it.
3. Create a `/datum/disease/advance`, add a `/datum/symptom/heal/plasma` with `power = 1`, set the disease's `affected_mob` to the human.
4. Call the symptom's `CanHeal()` with the disease, and read the tank's `total_moles()` now and about 30 seconds later.

Result on master: `CanHeal()` returned 0.75 (the maximum internals coefficient, `MAX_HEAL_COEFFICIENT_INTERNALS`). The tank held 8.73464 moles and still held 8.73464 after about 30 seconds, so nothing was drained.

## Cause

In `/datum/symptom/heal/plasma/CanHeal()` (`code/datums/diseases/advance/symptoms/heal.dm:513`), the internals branch is entered whenever the host has an internals tank:

```dm
var/obj/item/tank/internals/internals_tank = carbon_host.internal
if(internals_tank)
	...
	. += power * min(MAX_HEAL_COEFFICIENT_INTERNALS, internals_tank.distribute_pressure * HEALING_PER_BREATH_PRESSURE)
else // Check environment
```

(`heal.dm:522-529`). Nothing checks `TRAIT_NOBREATH`. A host with that trait does not breathe, so it never takes gas from the tank, yet it gets the full internals heal. The environment branch is the `else` of the same `if`, so hosts with an internals tank never use it.

## Fix

One commit, "Fix issue 95894: plasma fixation no longer heals from internals for hosts that don't breathe". It changes the condition to `if(internals_tank && !HAS_TRAIT(carbon_host, TRAIT_NOBREATH))` and adds a comment saying why. Because the environment check is the `else` branch, a non-breathing host with internals now falls through to the environment check, the same as a host with no tank.

The issue's reporter and a commenter discussed other designs: have Plasma Fixation drain the tank even for non-breathers (possibly at a different rate, or only plasma), or skip the `TRAIT_NOBREATH` check in the draining code. These were not implemented. The simplest option was taken: the tank stops counting as a healing source for non-breathers. The commenter wrote that they would find any other option more interesting than that one, so a maintainer may want a different design.

## Verification

After rebuilding and restarting the test server, with a non-breathing host (`no_breath`, breath mask, plasma tank as internals) on a tile with no plasma in the air:

- `CanHeal()` returned 0.
- The tank still did not drain (8.73464 moles).
- A control host that breathes normally with the same setup still got 0.75.

Not checked: the full virus cycle (reaching stage 4+ and healing real damage over time), a virus built with the actual Self-Respiration symptom, and other ways of getting `TRAIT_NOBREATH`. Only a mask-and-tank internals setup was used.

## Notes

- A non-breathing host standing in plasma-filled air still gets healed by the environment branch. In one earlier test on a contaminated tile, `CanHeal()` returned 0.0797 from plasma in the air, not from the tank. This is unchanged and was not part of the report.
- The healing from plasma in the bloodstream is also unchanged.
- The existing code comment says the tank's distribution pressure is used as an abstraction for breath contents. The fix keeps that abstraction and only gates it on breathing.
