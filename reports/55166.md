## Summary

The issue lists three problems for changelings who are also slime people (jellypeople) and use Split Body. Item 2, Chitinous Armor permanently reducing chemical regeneration, is a real bug: when the mind leaves the body wearing the armor, the armor's upkeep penalty is never removed, so it stays and stacks. The cause is that the armor action's cleanup runs after the mind has already moved, so it can no longer find the changeling datum. The fix remembers which changeling was slowed and uses that when the mind is gone. Item 3 (Arm Blade and organic shield retracting on a swap) was reproduced but looks like a side effect of the powers moving to the new body, and was not changed. Item 1 (automatic swap on death, no swap back into a dead body) matches the species' documented behaviour and was not changed.

## The bug

The issue text says: as a slime-person changeling, split bodies, then

1. "You automatically swap bodies on death and can't swap it back to revive."
2. "Chitinous Armor slows down chemicals regeneration on every other body. Stacks."
3. "Arm Blade and Organic Shield disappears if you change body (oversight?)."

Comments add that the chem regeneration can reach a negative rate, that a dead body keeps draining chems, and that the penalty stays if the extra body with the armor is destroyed.

## Reproduction

All steps were done on master with admin tools on the test server, using the Lua editor to drive the actions instead of clicking the UI.

1. Using the Lua editor, spawn a human, call `set_species` with `/datum/species/jelly/slime`, call `mind_initialize()`, add the changeling antagonist datum, and give the admin's ckey to that body. Set `chem_charges` to 75.
2. Give the changeling the Chitinous Armor power (`/datum/action/changeling/suit/armor`) and the Arm Blade power (`/datum/action/changeling/weapon/arm_blade`) with `give_power`, and use each with `try_to_sting`. After the armor, `chem_recharge_slowdown` was set and the body wore the armor ("We harden our flesh, creating a suit of armor!").
3. Run `slime_split:make_dupe()` on the species datum. This is what Split Body does after its do-after; the do-after was skipped, so the real action button was not clicked. The split also swaps the player into the new body.
4. Read `chem_recharge_slowdown` on the changeling datum and the suit of each body.

Observed on master:

- The changeling datum read `chem_recharge_slowdown = 0.125`, the armor's upkeep slowdown, even though the changeling was now in the other body.
- The old body still wore "the chitinous mass" and had no mind. Using the armor in the new body would have added another 0.125 and nothing removes either.
- With the Arm Blade active, the swap printed "With a sickening crunch, Unknown reforms their blade into an arm!" in the old body, so the blade was retracted by the swap (item 3).

Not reproduced: item 1 was not tested as a player action; it was only read in the code (see below). The comments' claims about negative regeneration, dead bodies and dusted bodies were not tested separately.

## Cause

Chitinous Armor is `/datum/action/changeling/suit/armor` with `recharge_slowdown = 0.125` (`code/modules/antagonists/changeling/powers/mutations.dm:545`). Wearing it adds that value to the changeling's `chem_recharge_slowdown` (`mutations.dm:167-168`), and casting it off subtracts it (`mutations.dm:149`). The value reduces the chem regeneration rate in `code/modules/antagonists/changeling/changeling.dm:275` and `:282`.

The subtraction only happens inside `check_suit`:

```dm
/datum/action/changeling/suit/proc/check_suit(mob/user)
	var/datum/antagonist/changeling/changeling = IS_CHANGELING(user)
	if(!ishuman(user) || !changeling)
		return 1
```

`IS_CHANGELING(user)` looks up the changeling datum through `user.mind`. `Remove()` (`mutations.dm:111-114`) calls `check_suit(remove_from)` when the action leaves a body. When a jellyperson swaps bodies, `/datum/mind/proc/transfer_to` (`code/datums/mind/_mind.dm:173`) moves the mind first (`:205-207`), and the action is granted to the new body afterwards. `/datum/action/proc/Grant` then calls `Remove(previous_owner)` (`code/datums/actions/action.dm:97-100`). By then the old body has no mind, `IS_CHANGELING(old body)` is null, `check_suit` returns early, the armor is not cast off, and the slowdown is never subtracted. Destroying or dusting a body goes through `clear_ref` and the same `Remove`, so it has the same result. This matches the comment from the issue thread that the debuff "doesn't account for stuff like extra bodies".

Item 1: `on_death_move_body` (`code/modules/mob/living/carbon/human/species_types/jellypeople.dm:270`) deliberately moves the mind to another available body when a slime person dies, and `can_swap` refuses dead bodies (`jellypeople.dm:489`), so swapping back into a dead body is not possible.

Item 3: the same Grant-then-Remove path calls the Arm Blade weapon action's `Remove()`, which retracts any held blade, so the blade disappears in the old body while the power itself moves to the new one.

## Fix

One commit, "Fix issue 55166: changeling chitinous armor chem slowdown stacked across jellyperson bodies", changes `code/modules/antagonists/changeling/powers/mutations.dm`:

- adds a `slowed_changeling` weakref to `/datum/action/changeling/suit`;
- `sting_action` stores a weakref to the changeling when it adds the slowdown;
- `check_suit` uses `IS_CHANGELING(user) || slowed_changeling?.resolve()`, so the cleanup still works when the user's mind has already left, and clears `slowed_changeling` after subtracting the slowdown.

This keeps the existing add/subtract bookkeeping and only fixes how the changeling is found. It also covers the body being deleted or dusted.

Not changed: item 1 (appears intended) and item 3 (a consequence of powers moving between bodies; arguably intended).

## Verification

After rebuilding and restarting the test server, the same setup (slime changeling) was used in two scenarios:

- Armor on body A, then Split Body. Chat showed "Unknown casts off their armor!". `chem_recharge_slowdown` was 0 and the old body's suit was nil.
- Armor used in the new body B (slowdown 0.125), then `swap_to_dupe` back to A. The armor was cast off, `chem_recharge_slowdown` was 0, and both bodies had no suit.

No runtime errors were seen in these runs.

Not checked: the "Split Body" button and its do-after were not used (procs were called directly); dusted, gibbed or dead bodies carrying the armor; negative regeneration with multiple stacked uses; Organic Shield and other suit-type powers; whether the changeling's other `chem_recharge_slowdown` powers behave the same way (below).

## Notes

- Other changeling powers also change `chem_recharge_slowdown` and were not examined: mimic voice (`powers/mimic_voice.dm:15,24,33`), pheromone receptors (`powers/pheromone_receptors.dm:19,31,35`), void adaptation (`powers/void_adaption.dm:62,69`) and darkness adaptation (`powers/darkness_adaptation.dm:39,50`). They may have the same problem if their upkeep is also left behind when the mind changes bodies, but this was not checked.
- Whether item 3 should be changed (keep the blade in the old body, or retract it) is a design call for maintainers.
